# Session 4: Docker and Kubernetes on GKE
Containers, the Kubernetes control loop, and your own cluster

**Date:** 2026-11-23, 16:30–19:00

## Goals
By the end of this session you can:
- Explain what a container is, how an image is built in layers, and why containers suit data pipelines.
- Build an image, run it, and push it to Artifact Registry.
- Explain the Kubernetes control loop, and what nodes, pods, deployments and services do.
- Create a GKE cluster with Terraform, choose between Standard and Autopilot, and keep its cost down.
- Deploy, scale, update and roll back a workload, and watch Kubernetes heal it.

You leave with the event generator running on your own GKE cluster, from an image you built.
